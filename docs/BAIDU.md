# 百度网盘授权教程

## 方案对比

| 方式 | 默认推荐 | Chromium | 云端样式 | 稳定性 |
| --- | --- | --- | --- | --- |
| bypy 命令行授权 | 是 | 不需要 | 原目录结构、逐文件可读 | 相对稳定 |
| 账号密码网页登录 | 兼容模式 | 需要 | tar.gz 归档 | 受百度页面和风控变化影响 |

## bypy 命令行授权

1. 使用默认方式安装项目：`./install.sh install`。
2. 打开 Fluidd 的“云端备份”。
3. 选择“百度网盘”。
4. 选择二级按钮“命令行授权”。
5. 目录保持 `/3D打印机备份` 或输入其他 bypy 内相对目录。
6. 保存配置，点击开始授权。
7. 打开 Fluidd 显示的 `openapi.baidu.com` 官方链接。
8. 在百度页面同意授权，将一次性授权码填回 Fluidd。
9. 显示“已连接百度网盘”后执行手动备份。

授权 token 保存在：

```text
printer_data/cloud_backup/bypy_home/.bypy
```

目录权限受限，API 不会把 token 返回 Fluidd。

## 为什么不能上传到百度根目录

百度 PCS 对 bypy 限制了应用目录：

```text
/apps/bypy
```

因此 Fluidd 中的 `/3D打印机备份` 对应网盘界面的：

```text
我的应用数据/bypy/3D打印机备份
```

这是百度接口限制，不是本项目自行添加的目录层级。

## 账号密码登录

先安装可选依赖：

```bash
./install.sh install --with-web-login
```

然后：

1. 在 Fluidd 选择“账号密码登录”二级按钮。
2. 填写百度账号、密码和目录。
3. 保存后发起登录。
4. 如出现图片验证码或短信验证码，在当前 Fluidd 页面提交。
5. 百度要求滑块、设备确认或其他交互风控时，系统会报告需要人工处理，不会反复尝试密码。

账号信息保存在 `printer_data/cloud_backup/credentials.json`，权限为 `0600`。密码对 Fluidd API 是只写字段，保存后不会再返回浏览器。

## 解除授权

Fluidd 中的“解除授权”会停止未完成的授权进程并删除对应本地 token/网页会话。正在上传或下载时不允许修改授权状态。
